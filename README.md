# PALATE

24-band parametric and dynamic EQ by [Carbonated Audio](https://carbonatedaudio.com/palate).

This repository holds the installers only. Grab the latest from **Releases**:

- `PALATE-Installer.pkg` - macOS, VST3 + AU + AAX, universal (Apple Silicon + Intel), macOS 11 or later. Needs a license key from your receipt.
- `PALATE-Demo-Installer.pkg` - the free demo: the full plugin, 60 seconds of audio then 10 seconds muted, on a loop.

Support: support@carbonatedaudio.com
